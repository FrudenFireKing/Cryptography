# CryptoLab2 — Основы криптографии: работа №2

Лабораторная работа №2: математические основы криптографии, вероятностные тесты
простоты, алгоритм RSA и атака Винера.

## Запуск

```bash
dotnet run   # из каталога CryptoLab2 (.NET 8/9/10 SDK или рантайм)
```

Вывод программы — демонстрация всех четырёх заданий с самопроверками.
Зерно генератора зафиксировано (`PseudoRandom.SetSeed(20251113)`), поэтому вывод воспроизводим от запуска к запуску.

## Ключевые решения

- **Без готовых криптобиблиотек.** Аналоги из ядра (`BigInteger.GreatestCommonDivisor`,
  `BigInteger.ModPow`) и сторонние криптопровайдеры не используются — все алгоритмы
  реализованы вручную. `System.Numerics.BigInteger` применяется как длинное целое,
  что прямо разрешено условием задания. Python не используется.
- **Stateless-сервис (задание 1).** `NumberTheoryService` не имеет полей: результат
  каждой операции зависит только от аргументов.
- **Шаблонный метод (задание 2).** Каркас теста (валидация вероятности, вычисление
  числа раундов t = ⌈ln(1−p)/ln(ε)⌉, цикл итераций) зафиксирован в базовом классе;
  поведение одной итерации переопределяется в наследниках.
- **Защита ключей (задание 3).** Генератор требует |p − q| > 2^(3b/4) (число итераций
  атаки Ферма ≈ (p−q)²/(8√n) становится экспоненциальным; порог 2^(b/2) — лишь граница
  полиномиальной зоны) и 3·d > n^(1/4) (условие теоремы Винера); нарушившие кандидаты
  отбрасываются.
- **Атака Винера (задание 4).** Неполные частные e/n получаются алгоритмом Евклида,
  подходящие дроби — рекуррентными формулами; кандидат φ(n) = (e·d−1)/k верифицируется
  полнотой квадрата дискриминанта x² − (n−φ+1)x + n = 0.
- **Формат шифртекста RSA.** [4 байта исходной длины] + блоки по ⌈bitLen(n)/8⌉ байт;
  блок открытого текста — не более ⌊(bitLen(n)−1)/8⌋ байт, чтобы значение блока было < n.
